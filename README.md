# 四川麻将工具箱

完全离线的四川麻将辅助网页，提供胡牌计番、四人流水结算和摸牌后出牌建议三个工具。在线版：[GitHub Pages](https://zhuxuanjian.github.io/sichuan-mahjong-calculator/)。

## 打开与切换

直接双击 `index.html` 即可在浏览器中使用；不需要安装依赖或启动服务。顶部导航提供三条路由：

- `#hu`：录入 13 张暗手牌与副露，选择定缺、胡牌方式和特殊情境，查看可胡牌与最高番型。
- `#settlement`：按发生顺序录入四位玩家的杠与胡牌事件，查看逐笔转账和净收支。
- `#discard`：录入摸牌后的 14 张等值手牌，选择一张弃牌，比较每种听牌的理论剩余数、点炮番和自摸番。

## 胡牌与计番

三门牌均按每种最多四张校验；定缺花色不能留在暗手或副露中。支持普通胡、七对与龙七对；四张相同牌在七对中按两对，且每个四张牌组计一根。多个合法拆分会选择原始番数最高者，最终番数最多为 4 番。

| 番型或情境 | 番数 | 条件 |
| --- | ---: | --- |
| 素胡 | 0 | 没有其他已确认番型 |
| 大对子 | 1 | 普通胡的所有暗手面子都是刻子 |
| 金钩钓 | 1 | 四组副露与一对暗手将 |
| 根 | 每个 1 | 每种四张相同牌各计一次 |
| 清一色 | 2 | 暗手与副露都只含同一花色 |
| 七对 | 2 | 无副露的七对结构 |
| 自摸 | 1 | 自摸胡 |
| 杠上花、海底捞月 | 各 1 | 仅自摸胡可选 |
| 杠上炮、抢杠胡 | 各 1 | 仅点炮胡可选 |

## 结算规则

胡牌的基础金额为 `2^番数`。点炮由点炮者分别向每位获胜者支付该金额；自摸由每位仍在对局中的其他玩家各支付该金额。一次点炮可以记录多位获胜者，全部获胜者在该事件之后退出，不能再参与后续转账。

杠的固定转账如下：

| 事件 | 转账 |
| --- | --- |
| 暗杠 | 每位其他仍在对局中的玩家向杠者支付 2 |
| 补杠 | 每位其他仍在对局中的玩家向杠者支付 1 |
| 直杠 | 点杠者向杠者支付 2 |

## 出牌建议的余张数

“理论剩余”使用已录入的暗手和副露计算；它不会读取牌河、其他玩家手牌或墙中信息。余张为 0 的结构听牌仍会显示为绝张，便于区分牌型与可用牌数。

## 测试

需要 Node.js。进入项目目录运行完整回归套件：

```sh
node --test tests/*.test.js
```

若 Windows 沙箱禁止 Node 测试运行器派生子进程，请在允许创建子进程的终端中执行同一命令。
