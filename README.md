# 四川麻将听牌计算器

一个完全离线的 13 张手牌听牌计算网页工具。

## 使用

直接双击 `index.html`，选择定缺花色，再点击牌面添加 13 张手牌。结果会自动显示可胡牌、胡型和理论剩余张数。

点击当前手牌中的任意一张可以将其移除。“撤销”可以恢复最近一次添加、移除或清空操作。

## 支持规则

- 万、筒、条三门，每种牌最多四张
- 胡牌时不能含定缺花色
- 普通胡（四组面子加一对将）、七对、龙七对
- 四张相同牌在七对中按两对计算
- 剩余张数只根据自己的 13 张手牌计算，不包含牌河和其他玩家的牌
- 不支持副露、番数与输赢金额计算

## 测试

安装 Node.js 后，在项目目录运行：

```sh
node --test tests/mahjong.test.js
```

如果 Windows 沙箱禁止测试运行器派生子进程，也可以使用同进程方式：

```sh
node tests/mahjong.test.js
```
